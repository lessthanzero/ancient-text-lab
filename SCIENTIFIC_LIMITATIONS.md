# Scientific Limitations (v0.2.0 research preview)

`ancient-text-lab` provides reusable contracts and deterministic helpers for ancient-script research. It does **not** decipher any script or assert historical readings.

- Benchmark pilots (Linear B transfer, Etruscan morphology) currently ship **synthetic fixtures**; scores are contract tests, not historical findings.
- External corpora listed in manifests are **not** redistributed here; fetch only under each provider’s license ([NOTICE](NOTICE)).
- Sibling projects (`linear-a`, `phaistos-disk`) keep corpus-specific claims; this lab does not upgrade their hypotheses to confirmed results.
