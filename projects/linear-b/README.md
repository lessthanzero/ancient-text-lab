# Linear A → Linear B transfer benchmark

This project measures recovery of a **citation-backed formal correspondence set**
against known Linear B endpoint labels. It is a validation harness for transfer
methods, not evidence that a Linear A sign has a particular sound value.

No historical score may be published until every gold correspondence has a
scholarly citation, its source data are checksum-pinned, and family-disjoint
splits plus the declared ablations have been run.
