# Indus Script Project (ancient-text-lab)

- **Origin**: Indus Valley Civilization (Harappan), c. 2600–1900 BCE.
- **Corpus**: ~4,000 inscriptions, predominantly short seals, tablets, and pottery graffiti.
- **Sign Characteristics**: Mean length ~4.6 signs; longest single surface ~26–34 signs. Signary size: ~400–700 signs.
- **Epistemic Invariant**: Dual-catalog normalization (Mahadevan 1977 vs Parpola 1994). Testing the Farmer-Sproat-Witzel non-linguistic emblem thesis against Dravidian/Indo-Aryan linguistic hypotheses using Markov conditional entropy and positional distribution models. Translation is strictly prohibited.
