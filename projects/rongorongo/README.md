# Rongorongo Project (ancient-text-lab)

- **Origin**: Rapa Nui (Easter Island), primarily 19th-century collection.
- **Corpus**: ~20 surviving wooden tablets and objects, ~14,000 glyph occurrences.
- **Palaeography**: Reverse boustrophedon reading order.
- **Epistemic Invariant**: Allograph variant reduction graph (reducing Barthel's 600 catalogue numbers to Pozdniakov's 52 core allographs). Priority given to astronomical and lunar calendar sequences (Tablet Mamari) and repetitive genealogy/liturgical chant structures over speculative narrative translations.
